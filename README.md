# Team Profile Website 🚀

Giao diện web giới thiệu profile thành viên nhóm với phong cách **Obsidian Dark Glassmorphism**, hiệu ứng cyber matrix coder rain, trang chào mừng TikTok Cinematic Welcome Intro, khung avatar hoạt ảnh Reyna Discord APNG và phát nhạc nền tự động.

## ✨ Tính Năng Nổi Bật
- **TikTok Welcome Screen**: Màn hình mở đầu ấn tượng với text kinetic typography, click mở vào trang chính.
- **Obsidian Dark Theme**: Thiết kế kính mờ (Glassmorphism) đen bóng, viền ánh bạc sắc sảo, không bị chói mắt.
- **Hiệu ứng Matrix Coder Rain**: Canvas hiệu ứng mưa code màu bạc hiện đại chạy ngầm phía sau.
- **Discord Reyna Avatar Frame**: Khung hiệu ứng động avatar hoạt ảnh Reyna (Discord APNG) cho các thành viên.
- **Audio Autoplay & Controller**: Nút bật/tắt nhạc nền lặp vô tận, tối ưu trải nghiệm người dùng.
- **Responsive**: Hiển thị chuẩn nét trên cả điện thoại (Mobile) và máy tính (Desktop).

## 📁 Cấu Trúc Thư Mục
```text
├── assets/
│   ├── avt1.png               # Avatar thành viên 1
│   ├── avt2.png               # Avatar thành viên 2
│   ├── avt3.png               # Avatar thành viên 3
│   ├── music.mp3              # Nhạc nền
│   └── reyna-decoration.png   # Khung avatar Discord Reyna APNG
├── index.html                 # Cấu trúc HTML chính
├── style.css                  # Toàn bộ CSS phong cách Obsidian Glassmorphism
├── script.js                   # Xử lý hiệu ứng matrix rain, welcome intro & audio
└── welcome_code.txt           # Mã nguồn mẫu màn hình welcome
```

## 🛠️ Sử Dụng
Mở trực tiếp file `index.html` trên trình duyệt web bất kỳ hoặc deploy lên Vercel / GitHub Pages / Netlify.
